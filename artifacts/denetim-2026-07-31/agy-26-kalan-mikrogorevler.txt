### 1. `src/core/docsContract.test.ts` Skill İçerik Paritesi Testi
* **NE:** `.claude/skills` ile `.agents/skills` arasındaki tüm skill'lerin yalnız isim klasör eşitliği değil, `SKILL.md` dosyalarının İÇERİK paritesinin de Vitest ile denetlenmesi. Şu anda sessizce sapan skill: `mamilas-ref`.
* **NEREDE:** [docsContract.test.ts](file:///Users/Muhammet/Desktop/mamilas-modern/src/core/docsContract.test.ts#L293-L301)
* **TAM DEĞİŞİKLİK:**
```ts
// src/core/docsContract.test.ts:293
  test('.claude/skills ile .agents/skills küme ve içerik olarak eşit — yeni skill tek yüzeyde doğmaz veya sapamaz', () => {
    const dirs = (base: string) =>
      readdirSync(resolve(REPO, base), { withFileTypes: true })
        .filter((d) => d.isDirectory())
        .map((d) => d.name)
        .sort();
    const claudeSkills = dirs('.claude/skills');
    expect(dirs('.agents/skills')).toEqual(claudeSkills);

    for (const skill of claudeSkills) {
      const a = read(`.claude/skills/${skill}/SKILL.md`).replace(/\r\n/g, '\n');
      const b = read(`.agents/skills/${skill}/SKILL.md`).replace(/\r\n/g, '\n');
      expect(b, `Skill "${skill}" içerik olarak .claude ve .agents arasında sapmış`).toBe(a);
    }
  });
```
* **YANLIŞ YAPILIRSA RİSK:** Claude ve Codex iki farklı skill talimatı okur; bir yüzeyde yapılan kural güncellemesi (ör. `mamilas-ref` referans yükleme yasası) diğer yüzeyde uygulanmaz ve hatalı prompt üretilir.
