MAMILAS fizik-eğitim videolarında kuvvet/fizik görselleştirme sistemi. Dünya render law "no icon/arrow/diagram standing in for the real object" der → fiziği MADDEDE + IŞIKTA göster, sembolde değil.

**Temel:** Kuvvet = sıcak **saffron FORCE-BLOOM** (ışık huzmesi/parıltısı) + gerçek fiziksel etki. **Asla ok/vektör/ikon değil.**

**Kodlama:**
- **Büyüklük (N)** = bloom BOYUTU + parlaklığı (büyük/parlak = güçlü).
- **Yön** = bloom hangi YÜZDEN ittiği (batı yüzünde bloom = doğuya iter).
- **Toplama / aynı yön** = blooms aynı yüzde BİRLEŞİR → tek daha büyük/parlak bloom. (Bileşke çamur arabası: @ali 10N bloom + @can 15N bloom → tek "25 N" bloom, araba fırlar.)
- **Çıkarma / zıt yön** = iki bloom ÇARPIŞIR (kafa kafaya), örtüşen kısım söner, net bloom güçlünün yönüne kalır. (halat çekme: batı 30N büyük vs doğu 20N küçük → net "10 N BATI"; kurdele batıya kayar.)
- **Dengelenmiş (R=0)** = eşit + zıt iki bloom (aynı boy) YOK olur, nesne tam durur, sakin nötr glow. (kitap: yer çekimi ↓ bloom = masa ↑ bloom → "R = 0 N".)
- **Sürtünme** = iki yüzey temas dikişinde bloom (harekete zıt sürüklenir). [Sürtünme videosu]

**Sayılar** = temiz **diegetik Türkçe kabartma etiket** ("10 N", "25 N", "R = 0 N", "BATI 10 N") — garble-guard negatifte (no morph/warp/English).

**İzinli istisna:** Öğretmen TAHTAYA kutu+ok çizerse o **diegetik çizim** (gerçek nesne değil, ders içeriği) — izinli. Firewall yalnız "gerçek nesne/aksiyon yerine ok koymayı" yasaklar.

**RENDER TUZAKLARI (Bileşke 52 kare denetiminde öğrenildi — ÖNEMLİ):**
- **"saffron force-bloom" ifadesi NB2'de gerçek SAFRAN/PAPATYA ÇİÇEĞİ ya da OK çiziyor.** Kullanma. Yerine:
  *"a soft rounded warm-GOLDEN GLOW of light (luminous energy aura) — NOT a flower/petal/saffron/arrow/arrowhead."*
  "saffron" (baharat/çiçek) ve "bloom" (çiçek) kelimelerini AT → "warm golden glow/aura".
- Glow **yalnız nesnede/temas noktasında**; karakter YÜZÜNDE glow olmasın ("never on a character's face/skin").
- Denge/duran nesne **yüzeyde durur, HAVADA UÇMAZ** ("rests ON the surface, not floating/levitating").
- Sayı etiketi: "R = 0 N" yazarken 0 ve N ayrık ("0 N", yoksa "ON" oluyor).

**CAST TUZAĞI:** NB2 arka plan çocuklarını default çeşitli/siyahi yapıyor. Sert kilitle:
*"EVERY child in frame, main AND background, is Turkish/Anatolian — warm Mediterranean skin, dark hair; NO Black/African or East-Asian child anywhere."* Ayrıca "cool-green highlight" Mira'nın cildini yeşile boyayabiliyor → "warm matte skin, green only on edges not skin".
